# 基于学习式全身控制与视觉感知的四足机器人自主抓取与放置

**Autonomous Quadrupedal Pick-and-Place via Learning-Based Whole-Body Control and Visual Perception**

本项目基于 Unitree Go2 四足机器人与 AgileX Piper 六自由度机械臂，使用 NVIDIA Isaac Sim 和 Isaac Lab 搭建四足机器人移动操作仿真平台。

项目围绕四足机器人运动控制、机械臂操作、视觉感知与全身协同控制展开，逐步实现四足机器人的自主移动、目标识别、物体抓取与放置。

---

## 1. 项目介绍（Project Overview）

本项目主要研究四足机器人移动操作（Mobile Manipulation）相关技术。

以 Unitree Go2 作为移动平台，AgileX Piper 作为操作机械臂，通过强化学习、运动控制与视觉感知等技术，逐步构建完整的四足机器人自主操作系统。

**主要研究内容：**

- 四足机器人强化学习运动控制（Reinforcement Learning）
- 四足机器人全身协同控制（Whole-Body Control）
- 机械臂实时遥操作与运动控制
- 机械臂末端轨迹规划与跟踪
- 视觉目标识别与空间定位
- 四足机器人自主移动操作
- 自主抓取与放置（Pick-and-Place）

## 6. 项目最终目标（Final Goal）

最终实现四足机器人自主移动操作系统，主要包括：

1. 四足机器人能够稳定行走，并根据任务需求自主移动。
2. 通过视觉感知识别目标物体并获取空间位置。
3. 根据目标位置完成底盘与机械臂的协同运动。
4. 机械臂能够自主完成目标物体抓取。
5. 四足机器人能够完成物体搬运与自主放置。

逐步实现从强化学习运动控制到视觉感知、机械臂操作与自主移动操作的完整技术链路。
